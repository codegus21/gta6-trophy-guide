Leonida Trophy Guide — an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI. Every trophy with its official name, description and grade, a guide in our own words that cites its sources, a roadmap to the platinum, missable trophies flagged, and a checklist saved in your browser with export, import, filters and a spoiler setting that hides story trophies until they are earned. Static files only: it opens in a desktop browser and works with the network off.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Or serve the `app/` folder with any static file server — no build step, no network requests at run time.
